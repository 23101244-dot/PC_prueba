# Directorio Corporativo (PC02)

Frontend en Quasar + Vue 3 que consume la API pública `https://dummyjson.com`.

## Instalar y ejecutar

```bash
npm install
npx quasar dev
```

## Rutas

| Ruta | Pregunta |
|---|---|
| `/` | P1 – Tabla de usuarios · P2 – Búsqueda |
| `/usuarios/:id` | P3 – Detalle · P4 – Compras |
| `/dashboard` | P5 – Indicadores |
| `/filtros` | P7 – Filtros combinados |
| `/comparar` | P8 – Comparar dos usuarios |
